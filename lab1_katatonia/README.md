## 2. Общие проблемы (касаются многих столбцов)

1. **Служебные строки внутри листа.** 34 строки ниже данных: пустые и подсказка с занятия. Если читать лист «как есть», в `ПсихПоздВозр` появятся значения `onehot`, `дети`, `родст_матери` — это не данные. → Берём только первые 814 строк.
2. **Множественный выбор в одной ячейке** через «, ». При этом **в самих вариантах ответа есть запятые**: «Ипохондрические, соматоформные и соматизированные расстройства», «Наличие отклонений, уточнить, в т.ч. обращаемость за медицинской помощью». Наивный `split(',')` превратит один вариант в два-три «мусорных». → Разбирать по словарю известных вариантов (длинные первыми), остаток считать свободным текстом.
3. **Пустая ячейка значит разное:**
   * в галочках («Наследственность», невротические расстройства, симптомы) — «ничего не отмечено» ≈ «нет / не известно»;
   * в `БерРодыМать` — по легенде прямо «**Без патологии, если пусто**»;
   * в `РанРазы` и `НевротРасстрШкола` есть явный вариант «Не оценивалось» — это **пропуск**, а не категория «норма» и не «отклонение».
4. **Опечатки и форматирование:** «Дядя/Тётя» и «Дядя/Тетя» (ё/е), «Мать» / «мать», пробелы по краям (179 из 206 значений `НевротРасстрШколаДоп` начинаются с пробела), «Задерджка» в тексте, нет пробела после запятой («Дефицит внимания,Трудности…»). → Нормализация: обрезка пробелов, «ё» → «е», схлопывание пробелов, сравнение без учёта регистра.
5. **Свободный текст** (`ПатРодовДруг`, `Ут2`, хвосты в `НевротРасстрШколаДоп`) почти не повторяется: 28 уникальных значений из 32 у `ПатРодовДруг`, 38 из 41 у `Ут2`. One-hot по такому тексту даст по столбцу на пациента. → Разметка по ключевым словам в несколько флагов, сам текст в модель не идёт.
6. **Редкость.** У многих признаков заполнено < 10 ячеек из 814 (`УО` — 1, `ПсихПоздВозр` — 6). One-hot по каждому родственнику и каждому расстройству даст почти пустые столбцы, на которых модель будет переобучаться. → Агрегировать (по расстройству, по группе родственников).
7. **Label encoding** — только там, где порядок очевиден. В этом наборе таких признаков два, и оба — производные (см. `насл_близость_родства` и `дошк_темп_развития`); исходные категориальные признаки номинальные → one-hot / multi-hot / бинарные флаги.

## 4. Разбор по признакам

### 4.1. Наследственность: столбцы 1–7

**Что это.** Один табличный вопрос анкеты «Наследственность [расстройство]»: строки — расстройства, галочки — родственники. В ячейке — список отмеченных родственников через запятую. Варианты родственников: Мать, Отец, Сиблинги, Дети, Бабка/Дед/Дядя-Тётя по линии матери, то же по линии отца.

**Проблемы.**
* Пустая ячейка у 785–813 пациентов из 814 — это «никто не отмечен». Отличить «нет» от «не спрашивали» нельзя (в полной анкете для этого есть отдельный столбец `Наследственность_ДиагнозНеИзвестен`, здесь его нет). Принимаю **пусто = 0 (отягощённость не указана)** и явно фиксирую это допущение.
* Опечатки: «Дядя/Тётя по линии матери» и «Дядя/Тетя по линии отца»; «Мать»/«мать».
* Очень мало данных: 1 случай у `УО`, 6 у `ПсихПоздВозр`, 7 у `НеврСтресс`, 9 у `Эпилепсия`. Полный multi-hot «7 расстройств × 10 родственников» = 70 столбцов, почти все из нулей.
* Строки-подсказки 831–837 в `ПсихПоздВозр`.

**Преобразование.** Родственников объединяю в 6 групп — ту же схему предлагали на занятии (подсказка в строках 831–837): `мать`, `отец`, `сиблинги`, `дети`, `родств_матери` (бабушка, дедушка, дядя/тётя по матери), `родств_отца`. Дальше строю признаки трёх видов:
1. **По расстройству** — бинарный флаг «есть хотя бы у одного родственника»: `насл_аффект`, `насл_псих_позд`, `насл_невр_стресс`, `насл_уо`, `насл_эпилепсия`, `насл_орг_цнс`, `насл_хим_завис` (7 столбцов). Для химической зависимости, где данных достаточно (125 пациентов), дополнительно **multi-hot по группам родственников** (`насл_хим_завис_мать` … `_родств_отца`); столбец «дети» оказался пустым и удаляется как константа.
2. **По группе родственников** — флаг «у родственника этой группы есть любое из 7 расстройств» (`насл_любое_мать` … `насл_любое_родств_отца`, 6 столбцов).
3. **Сводные:** `насл_число_расстройств` (сколько из 7 расстройств встречается в семье, 0–7) и **порядковый** `насл_близость_родства`: 0 — отягощённость не указана, 1 — только у родственников 2-й степени (бабушки, дедушки, дяди, тёти), 2 — есть родственник 1-й степени (родители, сиблинги, дети).

**Почему так.**
* Это **множественный выбор**, а не одна категория: у пациента может быть отмечено несколько родственников, поэтому one-hot по строке «Мать, Отец» (как по одной категории) неверен — нужен multi-hot по атомарным вариантам.
* Группировка нужна из-за редкости: отдельный столбец «Дед по линии отца с эпилепсией» с одной единицей — шум.
* Порядковое кодирование `насл_близость_родства` допустимо, потому что **порядок очевиден**: родственник 1-й степени имеет в среднем 50 % общих генов, 2-й степени — 25 %. Именно это и предлагалось в `Sheet1` («мать, отец → 1; бабка, дед → 2; другое → 3»), только я разворачиваю шкалу так, чтобы большее значение означало более близкое родство, и добавляю 0 для «нет».
* Номера 1/2/3 из `Sheet1` для «линии матери / линии отца / другое» как **одно число** не использую: линия матери и линия отца не упорядочены, это номинальный признак → отдельные флаги `родств_матери` и `родств_отца`.

### 4.2. `БерРодыМать` — беременность и роды у матери

**Что это.** Множественный выбор из 9 вариантов: «Без патологии», «Не оценивались (в т.ч. не известно)», «Патология беременности», «Токсикоз первой / второй половины беременности», «Психотравмирующие события», «Инфекционные заболевания», «Невынашивание беременности в анамнезе», «Другие тяжелые заболевания».

**Проблемы.**
* 8 пустых ячеек; легенда прямо говорит: **«Без патологии, если пусто»**.
* «Не оценивались» отмечено у 196 пациентов (24 %) — это пропуск, а не «норма».
* Логические противоречия: «Не оценивались + Без патологии» (2 случая), «Без патологии + Токсикоз / Инфекционные заболевания / Патология беременности» (3 случая).
* Редкие варианты: инфекции — 7, невынашивание — 6, психотравма — 5, другие заболевания — 4.

**Преобразование.**
* Пусто → «Без патологии» (по легенде).
* Multi-hot по патологиям: `бер_патология` (43), `бер_токсикоз_1` (26), `бер_токсикоз_2` (27), а 4 редких варианта объединены в `бер_прочее` (20). «Без патологии» — базовый уровень (все флаги 0), отдельного столбца не нужно.
* `бер_любая_патология` — хотя бы одна патология (77).
* `бер_не_оценивалось` — индикатор пропуска (196).
* Противоречия: если отмечена конкретная патология, она важнее отметки «Без патологии» (врач уточнил); «Не оценивались + Без патологии» → считаю «не оценивалось».

**Почему так.** Варианты ответа не упорядочены (токсикоз не «больше» инфекции) → не label encoding. Несколько вариантов у одного пациента → multi-hot. Пропуск «не оценивалось» нельзя приравнивать к норме: у 24 % пациентов сведений нет, и это само по себе информация — поэтому отдельный индикатор, а не удаление строк (потеряли бы четверть выборки).

### 4.3. `ПатРодов` и `ПатРодовДруг` — патология родов

**Что это.** `ПатРодов` — множественный выбор («Нет», «Преждевременные роды», «Гипоксия плода в родах», «Кесарево сечение», «Затяжные роды», «Наложение щипцов», «Стремительные роды», «Эклампсия») с полем «Другое» (так попал текст «родился в асфиксии »). `ПатРодовДруг` — отдельное поле свободного текста (32 заполненных).

**Проблемы.**
* 12 пустых `ПатРодов`; в отличие от `БерРодыМать`, легенда не говорит, что пусто = норма → это «нет данных».
* В `ПатРодовДруг` встречаются «нет» и «нет данных» (4 из 32), а 14 текстов стоят у пациентов с `ПатРодов` = «Нет» — то есть в основном поле «нет», а в дополнительном описана патология (обвитие пуповиной, кефалогематома, родовая травма).
* Часть текстов дублирует варианты основного поля: «Роды на 34 неделе» = преждевременные роды, «асфиксия плода», «5–6 баллов по Апгар, закричал не сразу» = гипоксия.

**Преобразование.**
* Multi-hot по частым вариантам: `роды_преждевременные`, `роды_гипоксия`, `роды_кесарево`, `роды_затяжные`; редкие (щипцы — 6, стремительные — 3, эклампсия — 1) → `роды_прочее`.
* Текст из «Другое» и из `ПатРодовДруг` размечается словарём ключевых слов: асфиксия / гипоксия / Апгар / «закричал не сразу» / «остановка сердца» → `роды_гипоксия`; «34 неделе», «недоношенными», «7 месяце» → `роды_преждевременные`; «кесарево» → `роды_кесарево`; остальной содержательный текст (обвитие, травма, гидроцефалия, низкий вес, резус-конфликт и т. п.) → `роды_прочее`; «нет», «нет данных» игнорируются.
* `роды_любая_патология` и индикатор `роды_нет_данных` (11 пациентов, у которых нет ни ответа, ни текста).
* Сам текст `ПатРодовДруг` удаляется.

**Почему так.** Свободный текст почти уникален — one-hot по нему бессмыслен, а выбросить его — потерять 14 случаев патологии, отмеченных только там. Словарная разметка сохраняет смысл и даёт числовые флаги. Медицинскую корректность словаря (например, относить ли «обвитие пуповиной» к гипоксии) стоит согласовать с врачом — в скрипте словарь вынесен в константу `BIRTH_TEXT_RULES`.

### 4.4. `РанРазы` и `Ут2` — раннее развитие до года

**Что это.** `РанРазы` — один из трёх вариантов: «В соответствии с возрастом» (641), «Наличие отклонений, уточнить, в т.ч. обращаемость за медицинской помощью» (46), «Не оценивалось» (127). `Ут2` — текстовое уточнение отклонений (41 заполнено).

**Проблемы.**
* «Не оценивалось» у 15,6 % — пропуск.
* Несогласованность: у 3 пациентов с «нормой» заполнено `Ут2` («Врожденный гепатит В», «отмечался гипертонус», «Снохождение; сноговорение»), у 8 пациентов с «отклонениями» `Ут2` пуст.
* В тексте опечатки и разнородные сведения: от задержки развития до бронхитов.

**Преобразование.**
* `ранразв_отклонения`: 1 — отклонения, 0 — норма, `NaN` — не оценивалось; плюс индикатор `ранразв_не_оценивалось`. Для моделей без поддержки пропусков `NaN` заменяется на 0 — информация не теряется, потому что есть индикатор.
* `Ут2` → три флага по ключевым словам: `ранразв_задержка` (задержка/отставание, «поздно начала говорить»), `ранразв_неврология` (невролог, гипертонус, гидроцефалия, ВЧД, судороги, парез, энцефалопатия), `ранразв_соматика` (бронхиты, пневмония, гепатит, аллергия, пиелонефрит, анемия и т. п.). Текст удаляется.
* 3 противоречивых случая не исправляю автоматически, а помечаю для проверки владельцем данных: флаги из `Ут2` у них проставятся, а `ранразв_отклонения` останется 0.

**Почему так.** Три значения — это не порядковая шкала «0 < 1 < 2»: «не оценивалось» не лежит между нормой и отклонением. Поэтому не label encoding 0/1/2, а бинарный признак + индикатор пропуска (эквивалентно one-hot с «нормой» в качестве базового уровня).

### 4.5. `НеротРасстрДетство` — невротические расстройства детского возраста

**Что это.** Множественный выбор: простые фобии (74), симбиотическая привязанность к значимому взрослому (46), энурез (40), логоневроз (33), эмоциональная лабильность (12), парейдолические переживания (12), снохождение (4), сноговорение (4), ипохондрические/соматоформные расстройства (4), энкопрез (2). Пусто у 649 из 814.

**Проблемы.** Вариант «Ипохондрические, соматоформные и соматизированные расстройства» содержит запятые — наивное разбиение даст две ложные категории. Пустая ячейка = ничего не отмечено. Часть сведений (фобии, сноговорение) попала в свободный текст «дошкольного» поля (п. 4.6).

**Преобразование.** Multi-hot: `детство_фобии`, `детство_симбиоз`, `детство_энурез`, `детство_логоневроз`, `детство_эмоц_лабильность`; 5 редких вариантов → `детство_прочее`; `детство_число_расстройств` — сколько вариантов отмечено (0–4). Фобии и сноговорение из текста дошкольного поля переносятся в соответствующие флаги (3 и 2 случая). Пусто → 0.

**Почему так.** Варианты номинальные и могут сочетаться → multi-hot. Число отмеченных расстройств — естественный количественный признак, его можно использовать как числовой.

### 4.6. `НевротРасстрШкола` + `НевротРасстрШколаДоп` — дошкольный возраст

**Что это.** По легенде столбец `НевротРасстрШкола` — «**Дошкольный возраст**» (имя вводит в заблуждение), вопрос с множественным выбором: «В соответствии с возрастом», «Наличие отклонений, уточнить, в т.ч. обращаемость за медицинской помощью», «Не оценивалось», «Отставание в психомоторном развитии», «Значительное опережение в психомоторном развитии», «Гиперактивность», «Дефицит внимания», «Диссоциация психического и физического развития», «Трудности установления контактов и общения в детском коллективе», «Особые увлечения» + «Другое».

**Главная находка: один ответ разрезан на два столбца по первой запятой** (как «Текст по столбцам» в Excel). Доказательства:
* вариант «Наличие отклонений, уточнить, …» в первом столбце никогда не встречается целиком — только обрывок до первой запятой «Наличие отклонений» (176 раз), а 26 значений второго столбца начинаются ровно с его продолжения « уточнить, в т.ч. обращаемость за медицинской помощью» (ещё в 5 значениях вариант записан целиком — когда он шёл в ответе вторым пунктом);
* 179 из 206 значений второго столбца начинаются с пробела — то, что остаётся после запятой в «…, Трудности…»;
* в `РанРазы` тот же вариант ответа записан целиком в одной ячейке.

Отсюда же «противоречия» вида «В соответствии с возрастом» + «Трудности установления контактов…» (33 пациента): это исходный ответ «В соответствии с возрастом, Трудности установления контактов…», в котором отмечены оба пункта.

**Преобразование.**
1. Склеить столбцы обратно (`первый + ", " + второй`) и разобрать по словарю вариантов; служебный текст «уточнить, в т.ч. обращаемость…» отбросить.
2. `дошк_отклонения`: 1 — отмечено «Наличие отклонений» или любое конкретное отклонение; 0 — только «В соответствии с возрастом»; `NaN` — «Не оценивалось» или пусто (77); плюс индикатор `дошк_не_оценивалось`.
3. Multi-hot конкретных отклонений: `дошк_трудности_общения` (146), `дошк_дефицит_внимания` (43), `дошк_гиперактивность` (36), `дошк_отставание` (31), `дошк_диссоциация` (10), `дошк_опережение` (4), `дошк_прочее` (особые увлечения и свободный текст: клаустрофобия, тревожность, судорожные припадки, …).
4. **Порядковый** `дошк_темп_развития`: −1 — отставание в психомоторном развитии, 0 — нет отклонений темпа, +1 — значительное опережение.

**Почему так.** Не склеив столбцы, мы бы получили бессмысленные категории («уточнить, в т.ч. обращаемость…») и ложные противоречия. Отклонения — номинальные и сочетаются → multi-hot. А вот «отставание — норма — опережение» — это одна ось темпа развития с **очевидным порядком**, поэтому для неё допустимо порядковое кодирование −1/0/+1 (порядок и направление однозначны, расстояния симметричны).

### 4.7. `Симптомы_е3` и `Симптомы_з2` — где отмечен симптом

**Что это.** Для диагностически важных симптомов (е-3 «разорванность или несообразность речи», з-2 «бедность речи») — когда симптом наблюдался: «Анамнез», «Статус», «Статус до лечения», «Статус после лечения» (можно несколько). Пусто — симптом не отмечен (596 и 347 пациентов).

**Проблемы.**
* «Статус» (151 и 370) и «Статус до лечения» (22 и 69) — по смыслу одно и то же, похоже на разные версии анкеты.
* Одно значение «Статус до лечения = Анамнез» — ручная запись.
* Наивный one-hot по строке «Анамнез, Статус» даст по 8–9 «категорий»-комбинаций.

**Преобразование.** Для каждого симптома 4 бинарных признака: `_анамнез`, `_статус` («Статус» или «Статус до лечения»), `_после_лечения`, `_есть` (отмечен хоть где-то). «Статус до лечения = Анамнез» → оба флага. Пусто → 0.

**Почему так.** Отметки не упорядочены и сочетаются → multi-hot по атомарным отметкам, а не one-hot по комбинациям. Слияние «Статус» и «Статус до лечения» убирает искусственное различие двух версий анкеты. «Симптом сохранился после лечения» — клинически отдельная информация, поэтому отдельный флаг, хоть он и редкий у е-3 (3 случая).

## 5. Что сознательно НЕ делаю

* **Не кодирую строки целиком** (one-hot по «Мать, Отец» как по одной категории): комбинаций много, они редкие, и модель не узнает, что «Мать, Отец» и «Мать» содержат общий пункт.
* **Не использую label encoding** для номинальных вариантов (родственники, виды патологии, отметки симптомов) — порядка нет. Порядковое кодирование только для двух производных признаков с очевидным порядком: `насл_близость_родства` (0 < 2-я степень < 1-я степень) и `дошк_темп_развития` (отставание < норма < опережение).
* **Не удаляю строки с пропусками**: «не оценивалось» встречается у 9–24 % пациентов в разных полях, удаление уничтожило бы заметную часть выборки. Вместо этого — индикаторы пропуска.
* **Не отправляю в модель свободный текст как есть** — только флаги, полученные словарём ключевых слов.

## 6. Как запустить пример

```bash
# из корня репозитория, после pip install -r requirements.txt
python lab1_katatonia/transform_katatonia.py
```

Скрипт печатает сводку и сохраняет:
* `lab1_katatonia/output/katatonia_encoded.csv` — 814 × 63, закодированные признаки (в репозиторий не входит: построчные данные пациентов);
* `lab1_katatonia/output/summary.csv` — для каждого признака: доля единиц, сумма, число пропусков.

Скрипт падает с понятной ошибкой, если в ячейке встретится неизвестный вариант ответа в «закрытых» полях (родственники, беременность, симптомы) — так новые опечатки не пройдут незамеченными.
